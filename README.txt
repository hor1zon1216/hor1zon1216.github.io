使用方法

1. 将 index.html、resources.html、style.css 上传到 hor1zon1216.github.io 仓库根目录。
2. index.html 和 style.css 会替换旧文件；resources.html 是新增的资料中心。
3. 在仓库中新建 files 文件夹，并按需要建立：
   files/frontend/
   files/programming/
   files/tools/
   files/design/
4. 上传资料后，在 resources.html 对应分类中加入文件链接。

示例：
<a class="file-item" href="files/programming/python-notes.pdf" target="_blank">Python 学习笔记</a>

注意：GitHub Pages 中的文件默认公开，请勿上传个人隐私或敏感资料。
