# hor1zon1216.github.io

yuhang hu 的个人主页，托管于 GitHub Pages。

## 使用方法

1. 新建仓库，名称必须为：`hor1zon1216.github.io`
2. 把本目录下的 `index.html` 和 `style.css` 上传到仓库根目录
3. 进入仓库 **Settings → Pages**
4. Source 选择 `Deploy from a branch` → Branch 选 `main` → 文件夹选 `/ (root)`
5. 保存后等待 1–10 分钟，访问：https://hor1zon1216.github.io

## 功能

- 响应式设计（手机 / 平板 / 电脑）
- 深色 / 浅色主题切换（自动记住选择）
- 关于、技能、项目、联系分区
- 纯 HTML + CSS + 少量 JS，无需构建

## 自定义

直接编辑 `index.html` 修改文字内容，或调整 `style.css` 中的颜色变量即可。
